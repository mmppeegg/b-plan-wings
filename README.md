# B-PLAN WINGS

一款純網頁的直向捲軸機翼射擊遊戲,向 1984 年的街機經典致敬的**原創作品**。

**Play: https://mmppeegg.github.io/b-plan-wings/**

- 全 30 關、13 種機翼(含 3 種隱藏翼)、Boss 血量四段變色
- 鍵盤:方向鍵移動、Z 射擊、X 拋棄機翼、M 靜音
- 觸控:拖曳移動(自動射擊)、PURGE 鈕拋翼
- 單一 HTML 檔案,引擎內嵌,離線可玩
